# Sources for the profile graphics

Each SVG in this folder is drawn for this profile. Places, numbers and lines come from the public pages below, as read on
17 October 2026. Map land comes from Natural Earth (public domain). Fonts embedded as subsets: Instrument Sans,
Instrument Serif, JetBrains Mono, Oswald and Source Serif 4, all under the SIL Open Font License 1.1.
